## 用你的眼睛，看懂每一球

CourtCast 的出发点是一个观赛体验问题：观众能够看到球进没进，却不总能看清机会是如何形成、一次选择为什么发生、另一条路又可能意味着什么。

产品连接比赛视频、官方记录与分析依据，把专业分析中的空间、对位、引力、出手环境和决策取舍，整理成球迷能够理解的解说。

团队以 CourtCast 参加 NBA × AWS「深度赛场」黑客松，获得铜奖，队伍编号为 **Team 15**。本页依据团队决赛路演与既有交互原型整理。

## 一个回合，三层理解

| 层次 | 要回答的问题 | 信息组织方式 |
| --- | --- | --- |
| 机会 | 谁牵动了防守？空间如何出现？ | 站位、补防、球员引力与出手环境 |
| 选择 | 此刻有哪些路线，各自有什么代价？ | 将出手与传球放在同一得分尺度上比较 |
| 结果 | 这一球发生了什么，对比赛有什么影响？ | 官方逐回合记录与胜率分析 |

三层信息分开表达：结果用于说明发生了什么，机会与选择用于解释局面。一次命中不会自动证明决策更好，一次投失也不会自动否定此前创造的机会。

## 团队产品的功能链

### 1. 认出是哪场、哪一球

输入真实比赛视频或一组比分条信息。识别环节读取比赛线索，再利用节次、时钟、比分、球队与结果，在官方逐回合记录中进行匹配。

模型读取是线索，官方记录是核对基础。能够唯一对应时，后续讲稿采用对齐后的官方比赛信息；不能确定时，不让不可靠的人名或比分继续进入讲解。

### 2. 将深度数据放回画面

将预期命中率、球员引力、出手环境等信息组织到具体回合中，解释持球人面对什么防守、空间如何改变、某个数字对应哪位球员。

官方记录、官方深度数据、规则估算、人工观察使用不同来源标签；位置标注与推理结论也分别表达。

### 3. 解释出手与传球的取舍

路演中的弗拉格样例对比自己出手与传给空位马绍尔，两种选择的规则估算分别为 **106 / 113**，采用每 100 次选择的预期得分这一共同尺度。

差值为 7。路演注明该样例没有超过误差门槛，因此产品呈现比较与场上条件，而不宣判传球更优。另一选择还依赖接球即投等条件；估算不是已经发生的真实得分。

决策估算的设计还考虑了区域样本门槛、向联盟平均收缩、贴防与空位调整、近筐罚球影响，以及样本不足时使用联盟平均。结论需要与相应假设和误差口径一起理解。

### 4. 形成有节奏的配音讲解片

先让观众看完原速回合，再进入拆解。把需要理解的选择停在关键时刻，用问题、数据和回答组织内容，而不是逐帧复述发生了什么。

讲稿、字幕、球员标注与数字卡围绕同一回合和时刻组织。配音与 CPU 出片纳入团队的云端工作流。

### 5. 让观众自己参与判断

在交互原型中，观众先选「自己突破出手」或「传给空位队友」，再揭晓估算差异与解释。点击补防或传球选项，画面上的位置标注与路线同步变化。

这种交互把分析从一段被动播放的讲解，变成一次有参与感的判断过程。

### 6. 从不同视角解释比赛

训练样例和产品设计覆盖进攻、防守与教练取舍：进攻方看如何创造机会，防守方看如何分配防守资源，教练看不同方案的代价。

决赛路演也明确记录了范围控制：比赛片证据不足时不启用某些多视角解释。公开原型展示这些解读方式，不能据此推断每种解释都曾在正式比赛素材中自动生成。

## 五个可体验的亮点

| 亮点 | 观众看到什么 | 核心交互 |
| --- | --- | --- |
| 读懂局面 | 持球、对位、补防与关键时刻 | 回看不同时间点 |
| 决策分析 | 自己出手与传球的比较 | 先选后揭晓、标注联动、查看依据 |
| 投篮选择 | 预期命中率与出手环境 | 把概率放回具体场景 |
| 球员引力 | 防守注意力与空间变化 | 理解牵引对队友的作用 |
| 防守取舍 | 协防保护与开放空间之间的交换 | 从另一侧看决策代价 |

公开版使用合成球场与示意位置。45%、106 / 113 等数字来自团队路演样例，页面不对合成画面进行在线识别、跟踪或模型推理。

## 三个产品取舍

### 先让人把球看完

保留原速回合与关键时刻拆解，减少频繁停顿与无助于理解的镜头运动。观赛节奏也是产品体验的一部分。

### 讲因果，让视觉服务理解

开场提问、过程解释、结尾回答。球员标签、路线、数据卡和交互应当指向同一个问题，而不是同时争夺注意力。

### 只讲有依据的

讲稿和查询共用证据包。数字差距不足以支持结论时，展示条件和差异；没有画面依据的动作与动机不凭空补写。

## 视觉与交互语言

| 元素 | 选择 |
| --- | --- |
| 暖金 | `#A99563`：球场标注、进度与重点 |
| 深棕 | `#592F23`：面板与整体氛围 |
| 象牙白 | `#FCF5E2`：标题、正文与主要入口 |
| 开场 | 球场格子组成眼睛，表达「看懂比赛」 |
| 幕间 | 保持近景，直接过渡到下一幕 |
| 收尾 | 篮球落地、两次回弹，承接作品介绍 |
| 操作 | 滚轮、键盘、章节按钮共用同一顺序，允许向前与回看 |
| 可访问性 | 原生交互、焦点管理、声音开关与减少动态效果 |

## 从这一球，走向每一场

团队路演提出的后续方向包括：在规则与检查器约束下由 Agent 组织讲稿；将全场胜率变化转化为赛后关键回合集锦；让观众先做选择再理解分析；在具备批量站位数据的前提下研究长期决策评价。

这些是产品演进方向，不作为本公开原型已经具备的能力。
