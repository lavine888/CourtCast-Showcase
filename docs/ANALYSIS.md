## 把「进没进」与「选得怎么样」分开

CourtCast 的数值分析由确定性规则引擎完成：读取事实与统计表，输出选项价值、比较依据和讲解结构。大模型参与画面理解与工具编排，规则引擎负责数值计算和评价条件。

单个决策快照中，设：

- `B`：联盟基准期望得分；实现中的基准为 1.15 分 / 次。
- `V_best`：当前可行选项中的最高期望得分。
- `V_chosen`：实际选择的期望得分。
- `R`：实际得分。

| 维度 | 计算 | 解释 |
| --- | --- | --- |
| 机会 | `V_best − B` | 这一刻创造了多好的机会 |
| 选择 | `V_chosen − V_best` | 是否兑现了当时最好的可行机会 |
| 结果 | `R − V_chosen` | 实际结果相对该选择的期望偏高还是偏低 |

三个量相加等于 `R − B`。在可行选项不变时，投进或投丢只改变「结果」，不改变「机会」和「选择」。单快照的选择项小于或等于零，表示相对最优可行选项的差额，不是球员的综合评分。

多次持球的实现进一步区分机会起点、过程峰值与最终选择，把创造机会和兑现机会分别记账；相邻持球之间的变化单独保留，避免把此前的损失归给最后出手的人。

## 一个选项值多少分

### 样本先收缩，再考虑出手环境

区域命中率采用向联盟同区域平均值收缩的形式：

```text
p_used = (makes + k × p_league) / (attempts + k)
```

`k` 是先验强度，由对应数据表提供；样本越少，结果越靠近联盟平均。球员自己的区域数据需满足上场时间与区域出手样本门槛，低于门槛时使用联盟口径。

引擎再结合两分 / 三分、防守距离与近筐罚球贡献等条件估算一次选择的期望得分。页面可以将「分 / 次」乘以 100，统一展示为「每 100 次选择的预期得分」。

来源随数字保留：统计赛季、源文件与 SHA-256、出手数、命中数、原始命中率、收缩后命中率、联盟基准、先验强度、上场分钟和公式。观众点数字时可以读到计算依据。

### 分数和结论分别处理

两个选项相差几分，不自动决定是否评价选择。实现同时检查区域误差门槛、比赛时刻、进攻时间、包夹与传球条件等约束；仓促出手和最后一攻有专门规则。

弗拉格样例中的 **106 / 113** 相差 7 分 / 每 100 次选择，仍在该样例误差范围内。产品据此说明另一侧的接球与出手条件，不将其宣判为确定更优的路线。

这类比较依赖「传到以后能按假设出手」等条件，是反事实规则估算，不是已经发生的官方统计或完整战术模拟。

## 官方 xFG 与决策价值各自回答什么

| 数据 | 回答的问题 | 使用方式 |
| --- | --- | --- |
| NBA 官方 xFG | 这次实际出手的预期命中概率是多少 | 描述已发生出手的环境与难度 |
| CourtCast 选项估算 | 在给定条件下，出手或传球分别预期得多少分 | 比较可行选项，保留条件和误差 |
| 实际命中与得分 | 这次出手最终怎样 | 记录结果，不倒推选择一定正确 |

官方 xFG 按比赛、节次、球员和时间窗口对齐。未发生的传球路线不能直接借用某次实际出手的官方 xFG，当作官方认可的反事实结论。

团队参数文件还保留了 **693 条 HOU–DAL 官方 xFG 记录**的样本校准摘要。这是官方数据在该子集上的校验，不能作为 CourtCast 自研模型的预测成绩，也不推及全联盟。

## 胜率与关键回合

### 模型形式

胜率模块使用正态分布累积分布函数 `Φ`：

```text
P(win) = Φ((lead + possession_adjustment) / (σ × √(seconds_left / 2880)))

有球权：possession_adjustment = +α
无球权：possession_adjustment = −α
```

它估算指定球队在当前分差、剩余时间和球权下的胜率。历史校准参数为 `σ = 18.25`、`α = 0.35`。

校准程序在进球、失误、防守篮板等球权交换明确的时刻构造状态，按对数损失拟合参数。状态量超过 40,000 时，拟合阶段使用固定随机种子的最多 40,000 个状态；以下汇总评估来自完整历史状态语料。

### 历史参数表记录

| 项目 | 数值 / 范围 |
| --- | --- |
| 参数表日期 | 2026-10-02 |
| 比赛数 | 1,230 场，2025–26 常规赛 |
| 历史状态数 | 212,267 |
| 对数损失 | 0.4847；固定预测 50% 的基线为 0.6931 |
| 整体十分箱最大偏差 | 2.1 个百分点 |
| 最后 5 分钟十分箱最大偏差 | 5.4 个百分点 |
| 最后 5 分钟且分差不超过 5 分的状态数 | 6,669；十分箱最大偏差为 5.4 个百分点 |

分箱偏差指每个预测概率区间内，平均预测胜率与实际获胜比例的差值。**2.1 不是单场误差上限、准确率或 ECE。** 这里没有独立留出测试集，不作为对新赛季或陌生比赛的泛化表现承诺。

### 从胜率变化找到关键回合

`game_impact.py` 将同一时刻事件前后的估算胜率变化，按绝对值排序。前提是有完整比赛记录且事件唯一对齐；覆盖出手、罚球和失误等事件，保留并列名次。

它表达「这次事件对当时胜负形势的冲击」，与「球员做出了最佳选择」是两个问题。未中投篮等情形还包含篮板归属假设，结果属于 CourtCast 估算。

## 防守也有取舍

防守交换模块把协防、夹击、换防和退防等候选方案放在同一得分尺度上比较：守住了哪里，又把什么机会留给了对手。

候选路线需要对应片段中的站位与人工观察依据，不能仅凭季节统计假设某位球员当时一定能够补到。实现分别保存选择评价和实际结果，使「选对了但对手投进」与「选错了但对手投丢」可以同时成立。

## 能复查的分析

引擎的数值、结论门槛和来源都随讲解结果保留。`read_film` 从已完成的成片证据中回答追问，播放器展示同一份数字和依据。
