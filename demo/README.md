# CourtCast · 原版 v6 前端

[作品介绍](../README.md) · [产品详解](../docs/PRODUCT.md) · [技术架构](../docs/ARCHITECTURE.md)

这里直接使用当时在本地修改的 v6 前端。HTML、CSS、JavaScript、比赛样例图片、眼睛拼图、品牌标志与字体保持原文件一致；本说明按展示仓库路径整理。

完整解压后双击仓库根目录 `index.html` 或本目录 `index.html`，也可使用任意静态服务器打开，无需安装依赖或构建。

保留眼睛开场、五幕导航、先选后揭晓、106 / 113 对比、球场标注、关键时刻回看、声音开关、自动导览和篮球收尾。滚轮、左右键与章节按钮共用同一顺序，支持向上回看与系统减少动态效果。

比赛图片与原样例标注沿用原文件，不替换为合成示意图。框线、路线和规则估算的来源与误差说明继续保留；静态页面不重新进行在线推理。

片尾仍跳到同级 `首屏视觉稿/index.html`，README 入口仍使用原 CloudFront 地址。历史目标页与已有图片一并保留；其 `assets/film.mp4` 与 `assets/eye_monk.mp4` 不在原素材中。隐藏版本预览依赖 v4、v5 目录，不属于此原版 v6 展示的默认入口。

本地字体嵌入 CSS；原始字体与 OFL 许可证位于 `assets/fonts/`。
