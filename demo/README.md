# CourtCast · 公开交互原型

[作品介绍](../README.md) · [产品详解](../docs/PRODUCT.md) · [技术架构](../docs/ARCHITECTURE.md)

完整下载并解压仓库后，双击根目录 `index.html` 或本目录 `index.html` 即可打开。
也可使用任意静态服务器，无需安装依赖或构建。

体验顺序：眼睛开场 → 读懂局面 → 决策分析 → 投篮选择 → 球员引力 → 防守取舍 → 篮球收尾。

使用滚轮、左右键或底部章节切换。向上可返回前一幕，第一幕继续向上返回开场。
在决策幕选择出手或传球，再揭晓对比；点击依据可查看位置与路线示意。
支持自动导览、关键时刻回看、声音开关、键盘和系统减少动态效果设置。

本公开版本使用 SVG 合成球场与示意位置，不包含 NBA 转播截图。
106 / 113、45% 等数字沿用团队路演样例；这些数字不由本页面对合成画面实时计算。
视频识别、官方数据查询、配音与出片属于团队的云端比赛方案，本页没有替代或模拟这些服务的成功调用。

样式中的字体以 data URI 嵌入，原始字体和 OFL 许可证保存在 `assets/fonts/`。
公开版片尾链接回作品介绍与产品文档，不指向旧的私有演示或云端服务。
